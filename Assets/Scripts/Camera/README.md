# Система камеры для режима "Сознание"

## Обзор

Система камеры состоит из двух основных компонентов:
- `CameraSettings.cs` - ScriptableObject с настройками камеры
- `CameraController.cs` - Компонент для управления камерой

## Использование

### 1. Создание настроек камеры

1. В Project окне, щелкните правой кнопкой мыши
2. Выберите `Create > BreakTheCycle > Camera Settings`
3. Назовите файл (например, "DefaultCameraSettings")
4. Настройте параметры в Inspector

### 2. Настройка CameraController

1. Добавьте компонент `CameraController` на любой GameObject в сцене
2. Назначьте созданный `CameraSettings` в поле "Camera Settings"
3. При необходимости назначьте:
   - `Target To Follow` - цель для слежения (обычно игрок)
   - `Camera Transform` - трансформ камеры (если не назначен, будет использована основная камера)

### 3. Интеграция с ConsciousnessController

`CameraController` автоматически найдет `ConsciousnessController` и будет получать от него направление движения через публичное свойство `MoveDirection`.

## Параметры CameraSettings

### Основные настройки
- **Camera Height** - высота камеры над игроком
- **Camera Angle X** - угол наклона камеры (X-ось)
- **Camera Angle Y** - угол поворота камеры (Y-ось)
- **Camera Smooth Speed** - скорость перемещения камеры
- **Camera Offset** - стандартное смещение камеры относительно игрока

### Динамическое смещение
- **Adjust Camera Direction** - включить смещение камеры в направлении движения
- **Direction Adjustment Strength** - сила смещения камеры в направлении движения
- **Camera Return Time** - время возврата камеры в стандартное положение после остановки игрока
- **Camera Damping Strength** - сила демпфирования для плавного торможения камеры
- **Direction Change Responsiveness** - скорость реакции на изменение направления движения
- **Max Look Ahead Distance** - максимальное расстояние опережения камеры

### Эффекты
- **Use Spring Effect** - применить эффект "пружины" к движению камеры
- **Direction Change Dot Threshold** - порог для определения резкого изменения направления
- **Abrupt Change Smoothing** - время сглаживания резкого изменения направления

## Преимущества новой системы

1. **Модульность** - настройки камеры вынесены в отдельный ScriptableObject
2. **Переиспользование** - один набор настроек можно использовать для разных сцен
3. **Легкость настройки** - все параметры собраны в одном месте
4. **Разделение ответственности** - логика камеры отделена от логики игрока

## Миграция

Если вы используете старую систему камеры в `ConsciousnessController`:
1. Создайте `CameraSettings` с текущими параметрами
2. Добавьте `CameraController` в сцену
3. Удалите логику камеры из `ConsciousnessController` (если требуется)

## Отладка

- Убедитесь, что `CameraSettings` назначены в `CameraController`
- Проверьте, что `ConsciousnessController` найден автоматически
- Используйте Debug.Log в `CameraController` для отслеживания проблем
